## DETAILED OWNERSHIP BREAKDOWN

### 1. WORKSPACE NETWORK OWNERSHIP

**Explicitly Owns:**
- ✅ Global availability of cognitive representations
- ✅ Broadcast construction and coordination
- ✅ Candidate admission evaluation and selection
- ✅ Coalition formation for related content
- ✅ State revision management (monotonic)

**Forbidden from owning:**
- ❌ Current experiential field organization
- ❌ Temporal continuity tracking
- ❌ Perspective generation
- ❌ Intentional context maintenance

---

### 2. MEMORY SYSTEM OWNERSHIP

**Explicitly Owns:**
- ✅ Persistent storage (semantic, episodic, procedural)
- ✅ Working memory activation tracking (temporary)
- ✅ Memory forms organization
- ✅ Provenance tracking for artifacts

**Shared responsibilities:**
- ⚠️ Current cognitive state (working memory)
- ⚠️ Activation-based accessibility

---

### 3. CONSCIOUSNESS OWNERSHIP (CONJECTURED)

- ⚠️ Perspective generation
- ⚠️ Intentional context maintenance
- ⚠️ Phenomenal binding integration

**Must NOT own:**
- ❌ Global availability (Workspace Network)
- ❌ Persistence (Memory System)
- ❌ Reasoning (Cognition)
- ❌ Decision making (Agency)
- ❌ Action execution (Action)

### 4. COGNITION OWNERSHIP (CONJECTURED - EMPTY SHELL)
