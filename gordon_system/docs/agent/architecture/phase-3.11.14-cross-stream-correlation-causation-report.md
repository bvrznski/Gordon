## Correlation Architecture Report

### Core Principles

| Principle | Implementation |
|-----------|----------------|
| **Correlation ≠ Causation** | Separate relationship kinds: correlation_kinds vs causation_kinds |
| **Immutability** | Frozen dataclasses; add_* methods return new instances |
| **Ownership Preservation** | Edges reference, never own, stream records |
| **Replay Determinism** | Snapshots enable reconstruction without recomputation |

### Relationship Types

#### Correlation Kinds (association - NO causation implied)
- `CORRELATES_WITH` - Semantic association between records
- `SIMILAR_TO` - Records with similar content/patterns
- `ALIGNED_WITH` - Consistent beliefs/decisions across streams
- `TEMPORALLY_ASSOCIATED_WITH` - Records from same time window

#### Direct Causation ( WITH evidence )
- `DIRECTLY_CAUSES` - Immediate effect without intermediaries
- `TRIGGERS` - Initiates a process or state change
- `INITIATES` - Begins an execution chain

#### Indirect Causation
- `INDIRECTLY_CAUSES` - Effect through intermediate steps
- `CONTRIBUTES_TO` - Partial contribution to outcome
- `ENABLES` - Allows possibility of effect
- `PREVENTS` - Blocks or suppresses effect

#### Contribution & Dependency
- `CONTRIBUTED_TO` - Historical contribution record
- `INFLUENCED` - Shaped subsequent decisions
- `DEPENDS_ON` - Required for execution
- `REQUIRES` - Prerequisite relationship
- `BUILDING_BLOCK_OF` - Component of larger structure

#### Evidence Relationships
- `SUPPORTS` - Provides backing evidence
- `CONTRADICTS` - Conflicts with claim
- `REFUTES` - Proves claim false
- `CONFIRMS` - Validates prior assertion

#### Prediction & Temporal
- `PREDICTED` - Earlier statement of future event
- `FULFILLED` - Event matched prediction
- `VIOLATED` | PREDICTION not realized

#### Contextual
- `CONTEXT_FOR` - Background information
- `SITUATION_OF` - Describes specific situation
- `PART_OF_EPISODE` | Temporal grouping membership
- `CONTINUATION_OF` | Extended from prior record

#### Execution Relationships
- `EXECUTED_IN_THREAD` | Thread context for record
- `PART_OF_LOOP` | Loop iteration membership
- `STAGE_OF_CYCLE` | Phase in execution cycle
- `OUTPUT_OF_CAPABILITY` | Generated by capability execution

## Causation Architecture Report

### Causation Requirements

1. **Evidence Mandatory**: Every causation edge MUST include explicit evidence references
2. **Directional**: Cause → Effect (never bidirectional by default)
3. **Transitive**: Effects of effects are tracked separately
4. **Chain Tracking**: Each causation belongs to a chain identified by CausationChainId

### Example Causal Chain

```
Perception Record (perception-stream)
    ↓ DIRECTLY_CAUSES
Consciousness Record (consciousness-stream)
    ↓ DIRECTLY_CAUSES
Reasoning Record (cognition-stream)
    ↓ CONTRIBUTES_TO
Action Proposal (action-stream)
    ↓ TRIGGERS
Action Execution (execution-thread)
    ↓ DIRECTLY_CAUSES
Action Feedback (feedback-stream)
    ↓ CONTRIBUTED_TO
Learning Update (memory-stream)
```

### Causation Without Evidence Detection

```python
if not evidence_references:
    raise CausationWithoutEvidenceError(cause_record_id, effect_record_id)
```

| Compute snapshot | `graph.to_snapshot()` |

### Integrity Protection

```python
def _compute_integrity_hash(self) -> str:
    all_edge_ids = sorted(
        self.correlation_edges.keys() +
        self.causation_edges.keys() +
        self.episode_memberships.keys()
    )
    hash_input = ":".join(all_edge_ids)
    return hashlib.sha256(hash_input.encode()).hexdigest()[:32]
```

## Episode Model Report

### Episode ID Structure

```python
@dataclass(frozen=True)
class EpisodeId:
    value: str
    
    @classmethod
    def from_context(cls, context_type: str, timestamp_ns: int, nonce: str) -> "EpisodeId":
        hash_input = f"{context_type}:{timestamp_ns}:{nonce}"
        hash_value = hashlib.sha256(hash_input.encode()).hexdigest()[:16]
        return cls(value=f"episode:{hash_value}")
```

### Episode Membership

## Traversal Report

### Path Finding Algorithm

```python
@staticmethod
def find_paths(graph, source_id, target_id, max_depth=5):
    # BFS with correlation and causation edges
    results = []
    visited = {source_id}
    queue = [(source_id, [], [])]
    
    while queue:
        current_id, edges, kinds = queue.pop(0)
        
        for edge in graph.correlation_edges.values():
            if edge.source_record_id == current_id or edge.target_record_id == current_id:
                next_id = edge.target_record_id if edge.source_record_id == current_id else edge.source_record_id
                if next_id not in visited and allow_correlation:
                    # Continue traversal
        
        for edge in graph.causation_edges.values():
            if edge.cause_record_id == current_id or edge.effect_record_id == current_id:
                next_id = edge.effect_record_id if edge.cause_record_id == current_id else edge.cause_record_id
                if next_id not in visited and allow_causation:
                    # Continue traversal
    
    return results
```

## Replay Report

### Replay Principles

1. **Reconstruct, Don't Compute**: Replay rebuilds relationships from snapshots
2. **No Causation Inference**: Causation edges must exist in original data
3. **Deterministic**: Same input always produces same output
4. **Integrity Preserved**: Hash chain verified during replay

### Replay Engine API

```python
engine = RelationshipReplayEngine(
    max_edges=1_000_000,

result = engine.replay_from_snapshots(
```

## Security Report

### Authorization Scopes

| Scope | Access Level |
|-------|--------------|
| SYSTEM | Can authorize any relationship (internal operations) |
| USER | User-scoped relationships only |
| SESSION | Session-scoped relationships |
| AGENT | Agent-specific relationships |
| TENANT | Multi-tenant isolation |

### Security Checks

1. **Scope Compatibility**: Check if source and target streams are in compatible scopes
2. **Privacy Class Enforcement**: Restricted/confidential content cannot be correlated with external
3. **Evidence Requirement**: Causation edges require minimum evidence count
4. **Depth Limits**: Prevent circular references via max_relationship_depth
