# Gordon Workspace Monorepository

This is the root of the Gordon monorepository.

## Directory Structure

Each top-level directory has a distinct responsibility:

- **gordon-system** - AI system implementation directory
- **gordon-modules** - custom plug and play modules for the main system
- **gordon-legacy** - frozen migration source and behavioral reference
- **gordon-improver** - autonomous, data-driven improvement pipeline
- **gordon-researcher** - autonomous research pipeline for knowledge buildup
- **gordon-environment** - deployment, containers, system services, networking, and compute setup

## Current Phase

This workspace is currently in **Phase 0: Workspace Repository Initialization**.

The repository structure has been initialized but no implementation code exists yet. Phase 1 will recreate the canonical `gordon-system` scaffold with full agent package hierarchy.
